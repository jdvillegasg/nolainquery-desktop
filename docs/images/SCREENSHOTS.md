# Screenshot capture list

Replace each SVG placeholder in this folder with a PNG of the same name
(keep the `.png` filenames listed below). Then update the image links in
`README.md` from `.svg` to `.png`.

Do **not** include API keys, OpenRouter keys, personal emails, or real
customer files. Use a public sample spreadsheet (or blur cell values).

| Save as | What to capture | How to get there |
| --- | --- | --- |
| `docs/images/settings-api-key.png` | Settings card: **API Key** input, **Save API Key**, tier status badge (no credits balance). Mask the key. | Sidebar → **Settings**. Crop to the Configuration card. |
| `docs/images/settings-byok.png` | **Model inference** with the OpenRouter key input and active-key badge visible. Mask the key. No mode toggle — OpenRouter is the only option. | Same Settings page, scroll to **Model inference**. |
| `docs/images/home-choose-dataset.png` | **Home** with a loaded file: **Choose dataset**, preview table, **Workbook tables** if Excel. | **Home** → **Choose dataset** → pick a harmless sample file. |
| `docs/images/ask-queries.png` | **Ask Queries** with a question and a finished answer card. | **Ask Queries** → ask something like `What columns do I have?` or a simple aggregation. |

Window size: at least 1280×720. Light theme, default UI. PNG, about 1600px wide.
